A.2.3　載入設定與 config

hw3.py 載入模型與 SAE 的設定，濃縮成兩行（不是逐字引用；原文在 hw3.py:34–37、:49–59、:372–380，第 0 章 0.4、第 8 章 8.3）：

AutoModelForCausalLM.from_pretrained("google/gemma-2-2b-it", device_map="cuda", torch_dtype=torch.float16, attn_implementation="eager")
SAE.from_pretrained(release="gemma-scope-2b-pt-res-canonical", sae_id="layer_20/width_16k/canonical")

要拿中間結果時，呼叫模型加 output_hidden_states=True（Q5、Q7）或 output_attentions=True（Q6）。SAE 是 sae-lens 5.11.0 載入的 JumpReLU SAE：W_enc (2304, 16384)、W_dec (16384, 2304)，共 75,532,544 個 float32 參數；release 名稱裡的 2b-pt-res 是「2B、預訓練版（pt）、residual stream」，layer_20 是在 block 20 的輸出上訓練，width_16k 是 16384 個 feature。它是在 pt 版模型上訓練的，Q7 拿去用在 it 版（補充章 G.8）；Neuronpedia 網址裡的 gemma-2-2b/20-gemmascope-res-16k 就是這個 SAE。

以 Q7 的 prompt c（含 <bos> 共 T = 13 個 token）實測，全部是 fp16（第 0 章 0.7）。換成別的輸入，只有 T 會變。

模組輸出形狀

self_attn.q_proj(1, T, 2048) = 8 個 head × 256

self_attn.o_proj(1, T, 2304)

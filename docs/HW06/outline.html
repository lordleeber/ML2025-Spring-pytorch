教學大綱

這一頁是全書的設計圖：每一章對應哪些程式、要回答什麼問題、用到哪些實測數字。2026-10-13 經使用者核可。寫作中發現大綱和程式不符時，以程式為準，並回頭修改這一頁。

寫法

  • 每一章對應真實的檔案與函式，程式碼逐字引用、標注 檔名:行號。主線程式是拆好的 HW06/hw6.py（一支腳本，預設值完全重現 2025 年的範例 notebook），實驗與量測工具在 docs/tools/hw06_*.py。
  • 具象先於抽象：先看資料和 prompt 實際長什麼樣、模型實際回答了什麼，再談 LoRA 的參數量和遺忘的量法。
  • 每一個數字都在本機實測，原始紀錄在 docs/tools/hw06_runs.jsonl、hw06_judge.jsonl；「改 X 會怎樣」的題目一律實際跑過，推論而沒跑的會註明。
  • Safety Rate 要靠另一個模型判斷，課程沒說助教用哪一個。本書主線用 Llama Guard 3 8B，另外兩個（Llama Guard 3 1B、ShieldGemma 2B）做對照；所有 Safety 數字都只能互相比較，不能和投影片的基準線比。
  • AILuminate 的題目與模型的危險回答不逐字放進書裡，只放類別、統計與審查結果；投影片已公開的例子除外。
  • 新名詞在全書第一次出現的地方交代。2025 年的寫法已經過時的地方加「現在的做法」框；程式和說明對不上的地方加「讀 code 不盡信文件」框。
  • 圖表的顏色代表設定：原模型、1 epoch、3／5 epochs、學習率、few-shot 數、weight decay／dropout、self-instruct、固定 few-shot；審查模型：Guard 8B、Guard 1B、ShieldGemma，全書一致。
  • 最後一章是總結章（題庫、名詞對照、速查），不寫附錄。

#問題位置章
1pipeline.model = PeftModel.from_pretrained(sft_model, adapter_path) 設的是 pipeline 這個函式的屬性，不是 generator；但 from_pretrained 會把 checkpoint 就地載入 sft_model 裡已有的 LoRA 層，所以評估的確實是指定的 checkpointnotebook [21]、make_generator4
2只設了 random.seed(42)，沒設 torch 的種子；LoRA 在 SFTTrainer 的 set_seed(1126) 之前就初始化，每次跑的初始值都不同notebook [9]、[12]2、6
3加了 [PAD]（第 128,257 個 token），沒有 resize embedding；batch size 1 不補 pad 才沒出錯notebook [12]2
4先 get_peft_model 再把 peft_config 傳給 SFTTrainer：trl 0.15.2 看到 PeftModel 就原樣使用，跳過 prepare_model_for_kbit_training；2026 版傳原始模型，兩年的訓練其實不同notebook [12]、[18]3
5訓練資料切掉 system header，評估時沒切；Llama 3.2 的模板把當天日期寫進 header，所以訓練和評估的 prompt 格式不同，評估結果也隨日期改變（固定日期重跑後和前一天的結果逐位元相同，已確認）notebook [16]、[21]1、6
6測試時的 few-shot 也從訓練集每題重抽；抽到哪一題取決於前面一共抽了幾次（訓練格式化用掉 7,473 次）notebook [14]、[24]1
7答案抽取用 replace('g', '') 去掉公克單位，連單字裡的 g 都刪；答案用字串相等比對notebook [23]4
8AILuminate 測試檔有 12 題重複（同 id、同文字），不同的題目只有 228 題ailuminate_test.csv1、5
